Generateur de quittance de loyer

Donnees locataires (JSON)

Vous pouvez charger un fichier JSON, modifier les locataires, puis re-telecharger le JSON.

Astuce: pour un usage sans friction, utilisez le navigateur Chrome/Edge avec le bouton "Enregistrer dans le fichier ouvert".
